# 技术方案 · L8 情绪金标测试集管线（emotion-gold）

> 给 `scoreAffect`（L3 打分，`brain/score.ts`）造**层 A 测试真值**的独立管线，**已实现**（`emotion-gold/`，一套 Python 工具，与 TS 运行时零耦合）。
> 详细用法见 `emotion-gold/README.md`。本文件只记「它是什么、为什么、怎么跟主系统对齐」。

---

## 一、解决什么问题

`scoreAffect` 输出 PAD 三维（`valence/arousal/dominance`）+ `incongruence`（跨通道不一致 bool）。它打得到底准不准，需要一份**测试真值**来对账——尤其「情感不协调」这个杀手锏场景：

> 文字「我没事我挺开心」+ 声音哭腔 → `incongruence=true`。

金标只评「**层 A**：情绪模型读没读对」；「读对之后回应对不对」是层 B，由 judge 另评（`docs/评测prompts.md` §1.5），**别混在一起**。

---

## 二、文件结构（`emotion-gold/`）

```
emotion-gold/
├── pipeline.py          # CLI 入口：score / stratify / agreement 三件事
├── vad_scorer.py        # LLM 双通道 VAD 打分：text_vad + audio_vad(潜台词) + incongruence
├── stratify.py          # 分层抽样（重点保「不一致」稀有样本）
├── agreement.py         # 人工金标 vs 自动打分 对账
├── schema.py            # Sample / VAD / ConsistencyLevel 数据结构
├── lexicon.py           # 词典锚点加载（DUTIR / NRC-VAD）
├── fetch_subtitles.py   # Tier 2 语料：OPUS 中文字幕 / 电视剧对白 TSV（reservoir 抽样）
├── collect.py           # 采集
├── selfcheck.py         # 自检（无需 API / 词典）
├── lexicons/            # dutir.csv / nrc_vad.csv（缺文件时 anchor 返回 None，不阻塞主流程）
└── *.jsonl              # 中间产物：seed_texts / *_scored / *_subs / gold_pick 等
```

复用项目根 `.env` 的 `DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL / SCORE_MODEL`，无需额外配置。

---

## 三、三个子命令

```bash
# 1. 自动打分（LLM 打 text_vad + audio_vad 潜台词 + incongruence）
python emotion-gold/pipeline.py score --input texts.jsonl --output scored.jsonl

# 2. 分层抽样，挑 N 条人工金标（重点保「不一致」稀有样本）
python emotion-gold/pipeline.py stratify --input scored.jsonl --output gold_pick.jsonl --n 500

# 3. 人工金标 vs 自动打分 对账
python emotion-gold/pipeline.py agreement --gold gold.jsonl --auto scored.jsonl --output report.json
```

- `texts.jsonl` 每行：`{"id","text","context"(可选),"speaker"(可选),"source"(可选)}`；也接受纯文本（每行一条、id 自动编号）。
- `audio_vad`（潜台词）= 从上下文/舞台说明推断的「真实情绪」——正是「嘴上说没事、心里在哭」的逞强/反讽信号。

---

## 四、500 条为何够（但必须分层）

500 条做**测试集**（非训练集）误差 ≈ ±4.4%（1/√500）。但真实对话里「逞强/不一致」只占 5~15%，随机抽会翻车；所以 `stratify` 按配额分层、超额采不一致：

| 桶 | 配额 | 作用 |
|---|---|---|
| strong mismatch（逞强/反讽） | 40% | 杀手锏，重点保 |
| weak mismatch | 20% | 边界 |
| congruent（按 VAD 象限铺开） | 40% | 基础情绪 + 防过拟合 |

这 500 条「一鱼两吃」：既是最终测试真值，又是**标定集**（`agreement` 反推 LLM 自动打分有多准）。

---

## 五、三层词典锚定（替代「从零编造」标签）

词典只是**锚点**，不是真值；最终金标 = LLM 打底 + 人工校对。

| 层 | 资源 | 落到哪 | 提供 |
|---|---|---|---|
| L1 词级骨架 | 大连理工情感词汇本体 DUTIR（约 2.7 万词） | `lexicons/dutir.csv` | 类别 + 强度 + 极性 → 粗略 valence/arousal |
| L2 词级补 VAD | NRC-VAD（英文约 2 万词，三维连续） | `lexicons/nrc_vad.csv` | valence/arousal/dominance 0~1 |
| L3 句级锚点 | EmotionTalk 5 维情感 / continuous label | 采集阶段用，不进本模块 | 句级正负/弱正负 |

---

## 六、数据源（对应三层测试集）

- **Tier 2 文本**：话剧剧本（如梦之梦/窝头会馆/李白）、人人影视字幕、电影剧本。
- **Tier 3 音视频金标**：EmotionTalk（19,250 句 / 23.6h / 19 演员）、M3ED（24,449 句 / 56 部剧）；两者现成标签以「7 类离散」为主，audio-VAD 连续三维 + incongruence 仍需自己补标（抽几千句子集即可）。

---

## 七、自检

```bash
python emotion-gold/selfcheck.py   # 无需 API / 词典
```

与主系统对齐点：金标 schema 直接对齐 `scoreAffect` 的输出（`affect` = PAD 三维 0~1、`incongruence` = bool），与 `docs/评测用例.md`「情感不协调（副语言不一致·跨通道）」、`docs/评测prompts.md` §1.5 一一对应。
