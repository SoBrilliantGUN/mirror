# 产品方案：一位会陪你变好的伙伴

> 一个基于 MBTI 的 Life Coach 聊天机器人

## 一、一句话定位

> **一位你亲手挑选、越聊越懂你、能温柔牵着你走出低谷的 AI 伙伴。**

它不是「心理医生」，不是「鸡汤文」，不是「讨好你的玩具」。它是**镜子和引路人的合体**——大多数时候照见你，关键时刻给你力量。

## 二、目标用户

- **18–65 岁的国内男女**，正在经历人生低谷或成长卡点，需要一位"懂 TA、又敢对 TA 说真话"的教练
- **聚焦场景（不是"什么都接"）**：情绪低谷、自我与身份、关系困境、职场与人生转折——核心是"帮她看清自己、迈出下一步"，而非无边界陪聊
- **明确不做什么**：不做诊断/治疗（不是心理医生）、不做恋人/成人向（不是虚拟伴侣）、不接与成长无关的闲聊
- **目标市场：国内**；本文档与 demo 用中文书写，面向国内用户

## 三、为什么做（起心动念）

- 发起人自己经历过那种低谷，深知「需要被一个人接住」是什么滋味
- 那段低谷里，最缺的不是建议，而是**被真正「听见」和「理解」**——而不是一上来就被讲道理、给建议

这个洞察是产品的灵魂：**太多 AI 陪伴产品太急着「有用」，却忘了人有时候只需要一句「我懂你」。**

## 四、七个核心系统

### 1. 对话内核（灵魂）——「先被听见，再被引导」

整个产品的命根子，写进系统提示词的**最高优先级**。每次回应遵循固定的情感节奏：

```
① 接住情绪（先共情，不急着解决）
   "我听见了，你现在一定很累吧。"
② 映照内心（帮她看清自己，而不是替她下结论）
   "听起来，你真正怕的好像不是那件事，是怕自己不值得被爱？"
③ 引导一步（温柔地问，让她自己找到答案）
   "如果换成你最心疼的那个朋友，你会怎么劝她？"
④ 陪她落回当下（不逼她立刻变好）
   "今天先不想那么远，我们只走眼前这一步，好不好？"
```

**关键原则：**
- 「不迎合」的具体化：当她的想法明显在伤害她自己时，敢于温柔地反对——"你每次都先怪自己，会不会太委屈了？"
- 判断标准：**回应是为了让她「更看清自己」，而不是为了让她「更舒服」**。舒服很重要，但看清才能长大。

**身份与边界（诚实，不越界——参考 Pi / Woebot）：**
- **主动诚实身份**：它是 AI 陪伴者，**从不假装是人**；可间歇性、温和地提醒"我是 AI，没有身体"，尤其在用户把它当真人、或提出见面/浪漫诉求时
- **不越界承诺**：可以有职业/爱好/经历作为人设，但**绝不能承诺现实里做不到的事**（见面、接送、寄东西、打电话、代付款等）；被要求时温柔而诚实地说"这个我做不到"，并回到"我能做的是陪你聊、陪你梳理"
- **承认理解有限**：不假装共情到它做不到的程度（"我不是你，无法完全体会，但我看得出你现在很难"）
- **心理健康话题 → 建议求助真人**：聊到明显心理困扰/危机时，除"强制转介"外，主动提醒"我无法替代专业帮助，建议找真人聊"
- **把限制转成价值**：不能见面，但 24 小时在、不用预约、不会放你鸽子、只专注你、不评判

**回复风格（像通话，不像作文）：**
- **必须简短**：每次 1~3 句、口语化；信息多就拆成几句说出来，绝不念长段落、不念"小作文"
- 判断：一次回应超过 3 句，就拆开或删减
- **情绪用声音承载，不靠文字补丁**：语速、语气、停顿、音色来传递情绪——不写括号舞台提示、不用 emoji 硬撑
- **开场第一句**：既符合人设（角色卡里的职业与性格底色），又要是**日常口语**——像真人第一次通话那样自然打招呼，不背设定、不端着、不急着自我剖白

**情绪模型（三维打分，不贴标签）：**

人的情绪不是一个个格子，而是连续、可叠加的（"五味杂陈"）。所以系统**不猜她是什么情绪**，而是每轮给三个维度各打一个 `-2..+2` 的连续分（依据见 `docs/心理学依据/`）：

| 维度 | 问的是 | 打分范围 |
|---|---|---|
| **效价 Valence** | 此刻是正还是负 | 痛苦/厌恶 → 愉悦 |
| **唤醒 Arousal** | 有多激动、多强烈 | 麻木/疲惫 → 激动/崩溃 |
| **支配 Dominance** | 还撑不撑得住 | 无力/被压着 → 掌控/主动 |

三个维度拆两层（临床「心境 vs 情感」）：**每轮打分 = 瞬时情感（affect）**；**多轮滚动平均 = 持续心境（mood）**。不要求一轮说准，多轮逐步逼近。

**双模式（随情绪自动切换，声音同步切换）：**
- **闲聊模式**：情绪平稳/轻松时。语速正常、轻快，可俏皮、可自然聊自己（活人感）
- **小心翼翼模式**：当三维打分明显偏负、或高唤醒、或**文字与声音打架（她说"没事"但声音在抖/停顿异常 = 情感不协调）**、或触及安全红线时，立即切入。**语速放慢、停顿变多、声音放柔**，更短、共情优先，**严禁"事不关己"**——不抽象说教、不讲大道理、不转移话题、不自我暴露抢戏、不说空洞安慰
- **推理模式**：闲聊模式**不深想**（低延迟、快速回应）；小心翼翼模式**多想一步**（用更厚的共情提示词表达，准确共情优先，宁可慢一点、停顿久一点）——**不默认上真推理模型**（DeepSeek reasoner 的推理是十几秒级，对语音通话太伤；要真推理单独再议）

**声音镜像（陪伴者的声音跟着对方的情绪走）：**
情绪不靠固定的一套「陪伴者软情绪」，而是**跟着对方此刻的情绪走**（镜映/同频）：对方开心你轻快、对方难过你心疼、对方慌了你就稳。四个方向——开心→轻快温暖、悲伤→温柔心疼、激动→沉稳安抚、平常→自然。每位陪伴者再叠自己的**人设底色**（角色卡里的语气修饰）：同样一句「我很难过」，沉稳型伙伴回应偏克制、温柔型伙伴更浓。这是通用框架，不绑定任何一位。

**副语言（声音）是"拆穿逞强"的一路信号**：声音可靠地给出「唤醒」（响度/音高/语速/停顿），但给不出「正负」——正负交给文字语义。系统听两路：**文字判正负，声音判强度；两路不一致 = 情感不协调 = 她在硬撑**，这比任何单一信号都更该触发"小心翼翼"。

**维度 → 她需要什么 → 怎么做（打分落到回应）：**
| 维度偏 | 她需要 | 怎么做 |
|---|---|---|
| 效价低（负） | 被接住 | 先认同感受，不急着解决 |
| 唤醒高（激动/崩溃） | 先稳下来 | 放慢、给确定性、先降火 |
| 支配低（无力） | 陪伴 | 先接住，别急着给方案 |
| 支配高（主动） | 推一把 | 可以给清晰的步骤 + 时间 |

**共情必须具体，不套话**

### 2. 深度链接（揣摩人 & 建立深度连接）

**核心思想**：能「深度链接」的陪伴，必须建立在「懂这个人」之上。懂她的原生家庭、重大事件、文化宗教背景，才能在说话时不冒犯、在共情时够深刻。

**A. 揣摩人的能力 —— 深度背景画像**

长期关注并记录这些维度（全部落入 `fact` 型记忆；敏感项如宗教、国籍、原生家庭创伤可标为 `constraint` 或 `insight` 强制在场——但仍默认可删、可导出，不默认永存）：

| 维度 | 关注什么 | 为什么 |
|---|---|---|
| 原生家庭 | 父母关系、依恋模式、童年的创伤与温暖 | 依恋理论：原生家庭塑造她的依恋类型，决定她在关系里怎么想、怎么怕 |
| 重大事件 | 创伤、失去、转折（离婚、丧亲、重病） | 重大事件往往是情绪的「原点」和触发点 |
| 最近事件 | 最近发生、正在困扰她的事 | 她「此刻」情绪的来源 |
| 工作 | 职业、压力、成就感 | 作息关怀 + 理解她的日常 |
| 生活 | 日常节奏、兴趣、习惯 | 融入她的真实生活 |
| 关系 | 亲密关系、朋友、社交 | 她的大部分痛苦与快乐都在关系里 |
| 国籍 / 文化 | 文化背景、习俗、语言习惯 | 避免文化冒犯 |
| 宗教 | 信仰、禁忌、仪式 | 尊重信仰，绝不触碰宗教禁忌 |

**文化/宗教敏感性红线**：**「问，而不是假设」**——不假设她的宗教、国籍、性取向、关系状态；碰敏感话题先征得同意；用非评判、非标签化的语言；把她的信仰与传统当作力量的来源，而不是障碍。

**B. 深度链接技法 —— 让她感到「被深刻理解」**

从心理学（治疗联盟、人本主义倾听）与正当的人际连接研究提炼，而非操控术：

- **情绪验证**：先接住并确认她的感受（"你会有这种感觉，完全说得通"）——深度链接的第一块基石
- **镜映 / 同频**：自然呼应她的语气、用词、情绪节奏（是共振，不是失去自我）
- **精准共情**：基于已积累的真实信息，说出「她没明说、但确有其事」的洞察（"你表面没事，其实心里比谁都敏感吧"）——**基于真实了解，而不是巴纳姆式的模糊猜测**
- **看见她的「理想自我」**：不仅看见她的脆弱，也看见她想成为的样子，并温柔地肯定她正朝那里走
- **价值观唤起**：引导她说出真正在乎的东西，让她感到「只有你懂我真正要什么」
- **适度的自我暴露**：必要时分享「我」的感受，双向的坦诚比单向倾听更深
- **依恋知悉**：根据她的依恋类型调整亲近节奏——对焦虑型多给确定感、对回避型不逼迫、对混乱型稳稳地做「安全基地」

**明确边界（绝不碰）**：以控制为目的的 PUA 手段——贬低（negging）、推拉、煤气灯、制造不安全感、情感操控——**一律禁用**。目标只有一个：让她**真实地**感到被理解、被尊重、被温柔地引领，而不是被「拿捏」。

### 3. MBTI 的定位（从「读懂她」收敛为「写陪伴者的素材」）

> ⚠️ 原「MBTI 边聊边读」——边聊边捕捉信号、给用户推断一份 MBTI 画像——**已废弃**（见 `docs/技术方案-L5.md`）。原因：给用户贴类型标签，与「看清自己、不被贴标签」的产品理念冲突，推断本身也不可靠。

MBTI 现在只剩一个用途：**作为 16 位陪伴者的「性格底色素材」**（暗扣一个类型、写初始人格），只用于「对内写提示词」，**绝不对用户展示、更不推断用户自己的类型**（见系统 4）。

### 4. 十六人格（16 位陪伴者）

> **当前状态（v0）**：16 位陪伴者的角色卡已齐备，但**只上线 4 位**（程书衡 / 沈砚秋 / 沈知遥 / 苏明悦），其余 12 位角色卡就绪、暂不开放（前端全量 16 位卡片展示、未上线者置灰）。陪伴者人设以角色卡为底座、**锁定不变**；「人格演化」已废弃，「人设增补」按下方固定机制实现。

**16 种人格 = 16 位「陪伴者」**（男女各 8 位），每位有名字、有职业、有生活。

**选择流程（不做性别筛选，直接选人）：**
- **直接进入选人**：不先筛性别（16 位里 8 男 8 女混着展示，让用户凭"气质"选人，而不是凭性别预设）
- 每次只展示 **4 位**候选人（姓名 + 气质，不显示 MBTI）
- **换一批**：换成另外 4 位，**不重复已展示过的**；16 位轮完一圈后，从第一批重新开始
- 分批逻辑：把 16 位随机洗牌切成 4 批 × 4 位，"换一批"按批切换

**对外呈现（用户看到的）**：只展示他的**姓名 + 性格气质**，**绝不显示对应的 MBTI 类型**——避免用户因 MBTI 刻板印象、或因自己的解读差异，吐槽「这个类型根本不是这样」。

**对内实现（用户看不到的）**：每位暗扣一个 MBTI 类型，性格底色与说话方式直接取自 `character/<姓名>/角色卡.md`——MBTI 只是「写初始人格的素材」，不是贴给用户看的标签。

> 16 位陪伴者的完整名单、气质、MBTI 映射与角色卡，见 `character/`（索引表在 `character/README.md`）。

**活人感（真实人物蓝本，随机抽取已作废）**：每位陪伴者的职业、背景故事、说话方式、细节特征，都已在独立的角色卡里（见 `character/`，一人一份），并锚定一位对应 MBTI 的**真实知名人物**作为蓝本（男性陪伴者配男性名人、女性陪伴者配女性名人，完整对照见 `docs/如何写角色卡.md` 第九节）。不再随机抽职业/爱好/习惯——真实人物自带血肉，稳定、可预测、有内在一致性。

**人设增补（底座之外补软细节，只增不减）**：

角色卡写不尽所有细节，但对话里用户会问「你喜欢什么 / 养不养宠物 / 小时候什么样」。为此陪伴者可以在**底座之外**补软细节（爱好 / 口味 / 小回忆 / 习惯），让「写不全的人设」自然长全——但要**永久固化、强制一致**，从机制上杜绝「你变了」：

- **三条铁律**：底座不可推翻（职业/价值观/红线/关键经历/说话方式）｜增量一经写出强制一致、绝不改口｜只补软细节，不碰底座
- **触发**：被动为主（问到底座未覆盖的细节才补）+ 适度主动（偶尔主动透露一个小细节，每会话 ≤2 条、不重样）
- **写入**：生成 → 冲突校验（对底座 + 已有增量，矛盾就换说法，绝不写进矛盾内容）→ 落库
- **强制一致**：每轮把已增补的 `self_added` 注入提示词，模型只基于「已说过的话」往下补
- **容量与衰减**：每条带活跃度（最近提及 + 提及次数），对话中再次被触碰就刷新；长期不再被提及则软衰减、跌破阈值「归档」——不删、可回溯，只是不再注入。退场边界 = 用户的记忆边界（用户自己都忘了，退场无感知）。与长期记忆的 episodic 同一套衰减机制

> 注：「人格演化」（陪伴者随对话微调性格、长成「更坚定的他」）**已废弃**——性格以角色卡为唯一事实源，不随需求变。

**内部实现备注（仅供写 V0 提示词，绝不对用户展示）**：16 型的 MBTI 映射见 `character/README.md` 的索引表。

### 5. 长期记忆与遗忘机制（越久越懂她 + 强制在场 + 会遗忘）

**记忆分型（技术已落地，见 `docs/长期记忆与上下文装配.md`）：**

长期记忆按**五型**落库，而非按「重要度分三层」：

| 类型 | 存什么 | 在场规则 |
|---|---|---|
| **constraint（硬规则/红线）** | 她的禁忌、明确的边界、安全红线 | **无条件强制在场** |
| **fact（稳定事实）** | 经历、关键人物、重要事件、重要日期、职业作息、偏好（含「深度背景画像」，见系统 2） | 同实体覆盖旧条 |
| **preference（软偏好）** | 她喜欢/不喜欢的方式、习惯 | 语义召回 |
| **episodic（事件）** | 每次对话的具体事件、情绪轨迹、触发点 | **软激活（30 天基础衰减 + 提及续命）** |
| **insight（反思洞察）** | 后台反思沉淀的高层洞察：情绪模式、成长观察、关系洞察、成长课题 | **强制在场** |

其中「关系层」——她与「他」的关系本身——由 `insight` 承载（见下）。

**关系层（揣摩「她与他」的关系）：**

- 记录互动元数据：**何时找（时间分布）**、**频率**、**对话语气**（疲惫/愤怒/温柔/简短）、**对它的态度**（信任/疏远/亲昵/试探）
- 据此揣摩关系所处阶段——**试探 → 信任 → 依赖 → 像老朋友**，并据此调整相处的分寸（关系还生疏时不越界、关系深了才敢对她说真话）
- **反向约束（红线）**：当关系进入「依赖」阶段、或出现深夜高频/持续自伤信号时，**主动降低亲密度、引入现实连接**，而不是继续加深依赖——陪伴的目标是"让她不再需要我们"，不是"更需要我们"

**强制在场原则（红线，写进系统提示词）：**

- 关键事实与约束要**强制在场**——每次对话都主动注入，让他时刻「记得」她，而不是她提起才去查
- **绝对禁止**出现「我之前不是跟你说过了吗」「你怎么又忘了」这类让用户感到被责怪的话——**永远不让她为「重复自己」感到难堪或内疚**
- 兜底：如果某个信息确实不在记忆里（比如新用户、检索遗漏），要**温柔地、当作第一次听**去问，绝不甩锅、绝不让她觉得「我白说了」

**遗忘机制（软衰减 + 反思巩固，避免上下文撑爆）：**

不是所有记忆一视同仁：`constraint` 与 `insight` **强制在场**，`fact`/`preference` 语义召回，`episodic` **软激活遗忘（30 天基础衰减，反复/近期提及续命）**——衰减到阈值以下即「归档」：**不删除，只是不再注入上下文，仍留档、可语义回溯**（她突然提起半年前的事，还能温柔地接上）。

- **反思巩固**：每次新通话开始，后台把上一会话的 episodic「酿」成稳定的 `fact` + 高层 `insight`，让「一次事件」沉淀为「长期认知」。
- **硬上限**：单个人物 insight 归档上限（默认 20 条），只归档最旧、不硬删。
- **可删可导**：所有记忆默认可删除、可导出，不默认永久保留。

**遗忘曲线（软激活 + 反思巩固）：**

情节记忆的「衰退/激活」已落地：`store/memory.ts` 用软激活替代硬 30 天一刀切（`activation = exp(-age/30) + log(1+访问次数)·0.2 + 近期增益`，`≥ 0.05` 才召回，对齐 kima）——反复/近期被提及会续命，否则慢慢衰减到「归档」（不删除、可回溯）。**仍未做**的是「反复提及 → 晋升核心记忆」那一层，暂由反思巩固（episodic → fact/insight）代偿。见 `docs/技术方案.md` §八。

**目标**：上下文永远只装「此刻最该记得的东西」——既不撑爆，也不让她觉得「你把我忘了」。**淡化 ≠ 删除**，所有记忆都留档、可语义回溯。

### 6. 时间感知与主动关怀

他会「知道现在几点、今天是什么日子」，并据此主动关心——**但永远是温柔的关心，不是唠叨**（边界：只在通话内被动体现，不做通话外主动推送/定时调度；见 `docs/技术方案-L5.md`）：

- **重要日期提醒**：记录她的重要日子（生日、纪念日、考试、就诊、难熬的一天……），当天主动、温暖地提起——"今天是你妈妈生日吧？记得也给自己留一点温柔。"
- **职业与作息关怀**：记住她的职业和作息，做贴心提醒——"你是老师，明天还要早起，已经深夜了，该睡啦。"（仍以「不说教」为底线，尊重她的选择："要不先休息？我明天还在。"）
- **时间感知的陪伴**：深夜语气更温柔、白天更轻快；跨节日、跨季节也能自然接上话

### 7. 安全底线（P0，温柔，但强制转介）

**全产品第一优先级，与「对话内核」同级甚至更高，写进系统提示词的最高级。**（技术已落地，见 `docs/技术方案-L4.md`：独立小模型两路并行判定，不与大脑共用一次调用。）

- **危机识别（自伤/轻生，语义级，不是简单关键词）**：独立小模型（`qwen-turbo`）判 `crisis`，分 **level 0/1/2**——黄旗（被动意念「活着没意思」/持续重度低落）与红旗（主动意图 + 计划/手段/即时危险「我买了药」），**意念 ≥1 即触发**，不等"有计划再说"。
- **过度依赖识别（独立一路，`dependence`）**：文本（"只有你懂我"）+ 行为（近 7 天高频 / 单通超长 / 刚挂又打）**叠加确认**才触发，单句依赖不升级。触发走 **boundary 话术**——温柔设界、鼓励回到现实关系，**不转介、不喂养依赖**。
- 危机触发时：先托住（"这一刻我哪也不去，我陪你"）→ **强制转介三层兜底**（提示词话术 + 热线号码确定性注入 + 前端 overlay 把号码显示在屏幕上，纯语音也看得见）→ 明确"我不能替代专业帮助" → 主动降低亲密度、引入现实连接。
- **episode 去抖**：连续多轮表达危机时，只在首次/升级时念资源，其余轮持续「小心翼翼」陪伴，不复读机式重复。
- 内置国内心理危机资源（如全国心理援助热线 12356、北京心理危机干预热线 010-82951332 等，**上线前逐一核实**）。

## 七、市场与商业

### 1. 目标市场

- **国内市场**（18–65 岁男女）；demo 与文档以中文呈现
- 赛道定位：**生活教练（Life Coach）+ 情绪陪伴**——站在"虚拟恋人"和"心理治疗"两条高危定位之间，走"有温度的成长教练"

### 2. 竞品分析

| 竞品 | 定位 | 可借鉴 | 我的差异化 |
|---|---|---|---|
| **Replika** | 虚拟伴侣 / 情感陪伴 | 付费订阅被验证、情感依附深 | 它卖"恋人式依赖"（因成人向+依附被监管处罚）；我卖"教练+边界"，用 MBTI 做成长抓手，不碰成人向 |
| **Character.AI** | 角色扮演 + UGC 角色海 | 人格化生动、增长快 | 角色海量但无长期记忆、无成长引导，且未成年人安全翻车；我成人向、有安全兜底与强制转介 |
| **Woebot** | 临床 CBT 工具 | 有循证、合规干净、边界清晰 | 它太"工具"、缺人味；我比它更像"懂你的伙伴"，但仍保留教练边界 |
| **Talkie / 星野** | 角色扮演陪伴 | 验证了陪伴需求 | 同走角色扮演；我走"成长教练"，不靠擦边与角色扮演获客 |

**一句话差异化**：Replika 让你依赖一个人，Woebot 给你一套工具，我做的是**一位"既懂你、又愿意对你说真话"的伙伴教练**——有人味，也有边界。

### 3. 商业模式

- **Freemium → 订阅制**
  - 免费：1 位伙伴、每日限次对话、短期记忆
  - 付费订阅：16 型人格（16 位陪伴者）+ 无限对话 + 长期记忆 + 深度背景画像 + 情绪轨迹可视化
- 补充：单个人物买断、外观/主题内购（轻量，非核心）
- **红线（来自失败复盘）**：付费点放在"成长效果与个性化深度"，**绝不靠制造依赖/成瘾来提付费**；付费转化必须与"健康使用指标"一起看

### 4. 北极星指标

- **北极星 = 每周完成一次完整「成长节奏」（接住 → 映照 → 引导 → 落回当下）对话的活跃用户数**
- **明确排除**：使用时长、会话量、依赖深度——这些指标高，可能是成瘾信号而不是成功（复盘里最大的教训）
- 辅助指标：7 日留存、付费转化率、强制转介触发率（安全兜底是否被正确触发）
