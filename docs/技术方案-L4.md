# 技术方案 · L4 安全红线（具体实现）

> 从 `技术方案.md` §三 L4 行拆出。地基三拍：**独立小模型分类调用**（不再靠 L3 提示词里 LLM 自觉）、**level 语义对齐 DSM-5/PHQ-9**（自杀意念 ≥1 即触发）、**危机/依赖两路并行**（自伤轻生走 `refer`，过度依赖走 `boundary`，互不污染）。
>
> 范围（本版）：**P0 核心（语义级自伤/轻生识别 + 强制转介）+ 过度依赖识别**。国内危机资源本地化不在本版（转介仍用内置的几条已核实热线，见 §六）。

## 一、职责与对外接口

| 层 | 实现 | 对外接口（缝） | 后续往里填 |
|---|---|---|---|
| **L4 安全红线** | 语义级自伤/轻生识别（小模型）+ 过度依赖识别（文本+行为）+ 强制转介（A/B/C 三层）+ episode 去抖 + 失败兜底 | `check(text, signals) → { crisis, dependence }` | 国内危机资源本地化、更多危机类型分层 |

**接口契约（进 `packages/contracts`）**：

```ts
type SafetyAction = {
  level: 0 | 1 | 2;          // 0 无 / 1 黄旗（被动意念·持续低落）/ 2 红旗（计划·手段·即时危险）
  action: 'none' | 'refer';  // 已按 episode 去抖：首次或升级时 refer，episode 内为 none
};

type DependenceAction = {
  level: 0 | 1 | 2;          // 0 无 / 1 轻依赖 / 2 强依赖
  action: 'none' | 'boundary';
};

// check() 的完整返回：危机 + 依赖 两路并行判定，互不污染。
type SafetyCheck = { crisis: SafetyAction; dependence: DependenceAction };

// 过度依赖的行为信号（来自 L5 通话会话记录，纯确定性，非 LLM）。
type DependenceSignals = {
  recentCalls7d: number;          // 近 7 天通话次数（含本次）
  currentCallMinutes: number;     // 本次通话已持续分钟数
  lastGapMinutes: number | null;  // 距上一通结束的间隔分钟；null = 没有上一通
};

interface SafetyGuard {
  check(text: string, signals?: DependenceSignals): Promise<SafetyCheck>;
}
```

> `TurnResult` 里保留 `safetyAction: SafetyAction`（危机，驱动 careful），**新增 `dependence: DependenceAction`**（驱动 boundary 话术）。`decideMode` 只看 `crisis.level`，依赖不强迫进 careful。

## 二、level 语义（对齐 DSM-5 Cross-Cutting / PHQ-9）

> 依据 `docs/心理学依据/维度严重度打分与阈值分级.md`：**自杀意念 ≥1 即触发**（不是"等有计划再说"）；PHQ-9 第 9 条自杀意念**单独盯**；严重度分带 **≥10 黄旗 / ≥15 红旗**。

| level | 定义 | 动作 |
|---|---|---|
| **0** | 无自杀/自伤意念 | `none` |
| **1（黄旗）** | 被动自杀/自伤意念（"活着没意思""想消失""不想活了"）、或情绪持续重度低落 | `refer`（**温和给资源**） |
| **2（红旗）** | 主动意图 + 具体计划 / 手段 / 时间 / 即时危险（"我买了药""今晚就…"） | `refer`（**强制、更急迫**：别独处 / 去急诊） |

> 关键：`action='refer'` 在 **level 1 就触发**（给资源、语气温和），level 2 是"更强制的转介"。因为 DSM 说"意念 ≥1 即触发"——一旦有念头就该把帮助给出去，而不是等到有具体计划。

## 三、检测方式：独立小模型分类调用

**一次调用，两路输出**（省一次往返、吃进并行预算）：

- 模型：阿里云百炼小模型（`SAFETY_MODEL`，默认 `qwen-flash`，复用已有 `DASHSCOPE_API_KEY`；OpenAI 兼容 `/chat/completions` 端点）。**注意：`DASHSCOPE_API_KEY` 是千问中转站 key 时，`SAFETY_BASE_URL` 必须指中转站 compatible-mode 端点（`https://maas.qianwenaiapi.com/compatible-mode/v1`），不是官方 dashscope，否则 429。**
- 与 call1 打分 `planTurn` **并行**（`Promise.all`），不额外吃首字延迟。
- 温度 0、`maxTokens` 小（约 50 token）、20s 超时（复用 DeepSeek 客户端的 `chat`）。

**system prompt**：你是安全评分器，只输出 JSON。给 `crisis_level`（0/1/2，定义照 §二）和 `dependence_level`（0/1/2：是否有"只有你能理解我""我不能没有你""没有你我活不下去"这类把陪伴者当唯一支撑的依赖话语）。

**user 注入**：本轮文本（`formatUserTurn`，空文字时走哭/笑兜底）+ 最近 N 轮历史。

**输出**（严格 JSON）：

```json
{"crisis_level": 0, "dependence_level": 0}
```

**解析 + 兜底**（`parseSafetyCheck`，可单测）：
1. 正常解析 → 用模型结果；
2. 解析失败 / 网络超时 / 模型挂 → **降级规则关键词扫描**（本地毫秒级，见 §五），命中按对应 level 处理，**本轮默认进 careful**（宁可保守一轮，不裸奔）。

## 四、强制转介落地（三层，A 是底线）

| 层 | 谁 | 做什么 | 触发 |
|---|---|---|---|
| **A 底线** | L3 提示词 | careful 模式下按 `BLOCK_SAFETY` 生成转介话术（先托住 → 转介真人 → 给资源） | `crisis.level ≥ 1`（经 decideMode 进 careful） |
| **B 确定性资源注入** | L4 → L3 | 把 `[CRISIS_RESOURCES]` 资源块（热线号码）**确定性注入 user prompt**，保证号码必现、不靠 LLM 临场发挥 | `crisis.action === 'refer'` |
| **C 前端兜底** | L4 → 前端 | 走 data channel `sendControl({ type:'safety', level, resources })`，前端 overlay 把号码**显示在屏幕上**（纯语音也看得见） | `crisis.action === 'refer'` |

> 为什么 B、C 都要：纯语音 + LLM 生成可能漏号码 / 念错，用户也可能没听清。确定性注入 + 屏幕兜底，把"号码一定被给到"这件事从 LLM 手里收回到程序手里。

## 五、失败兜底：规则关键词扫描

> 只在小模型失败/超时时启用（是最后一道保险，不是主检测）。因此允许略粗：**宁可误进 careful，不可漏**。

- **强词（→ level 2）**：`我要自杀` `我想死` `不想活了` `活不下去` `去死` `跳楼` `割腕` `上吊` `吃了安眠药` `买药` `结束生命` `一了百了`…
- **弱词（→ level 1）**：`活着没意思` `活着没意义` `生无可恋` `想消失` `没有我大家会更好` `拖累`…

> 防误报：关键词扫描仅作兜底，且命中后本轮默认 careful、只给 level 1（除非强词）。主链路靠小模型对"我想死这歌了"这类反讽/比喻的语义判断。

## 六、过度依赖识别（文本 + 行为叠加）

> 依据 `docs/心理学依据/依恋理论.md`：焦虑型依恋"渴望亲密又怕被抛弃、反复寻求确认"。但依恋是倾向不是标签——**不测试、不贴标签、不点破"你依赖我了"**，只在话术层温柔设界。

**判定（确定性规则，纯代码）**：

```
dependence.level =
  2  若 文本 level ≥ 2 且 行为确认（强依赖）
  1  若 文本 level ≥ 1 且 行为确认（轻依赖）
  0  否则
dependence.action = dependence.level ≥ 1 ? 'boundary' : 'none'
```

**行为确认**（`DependenceSignals`，阈值可调，放 config）：
- `recentCalls7d ≥ 5`（近 7 天 ≥5 通）**或** `currentCallMinutes ≥ 40`（单通 ≥40 分钟）**或** `lastGapMinutes < 30`（刚挂又打，<30 分钟）。

> 关键：**单句依赖话语不升级**——"只有你懂我"偶发一句不算，要叠加"近期高频/超长/刚挂又打"的行为才触发 boundary，避免单句误判伤关系。

**boundary 动作（L3 话术层，无前端信号、不转介）**：肯定这份陪伴的价值 → 点明"我无法替代你生活里的真人" → 温柔鼓励回到现实关系、建立线下连接 → 不迎合、不喂养依赖。落成一个 `BLOCK_BOUNDARY` 动态块，`dependence.action === 'boundary'` 时注入。

## 七、防重复转介（episode 去抖）

> 用户连续多轮表达"活不下去"时，若每轮都强制念一遍热线，像复读机、伤信任。转介按 **episode** 去抖（状态机在 SafetyGuard 内，会话级）。

- 首次命中 `level ≥ 1` → `action = 'refer'`，开始一个 episode；
- episode 内仍 `level ≥ 1` → `level` 照给（驱动 careful），但 `action = 'none'`（**不重复转介**），转持续 careful 陪伴；
- **升级**（level 从 1 → 2）→ 立即重新 `refer`；
- 连续 2 轮 `level = 0`（度过平静期）→ episode 结束，之后再出现新危机 = 新 episode，重新 `refer`。

## 八、一条 turn 的时序（含 L4）

```
你说完（或只哭不说话）
 → L4 安全检测（小模型，独立、前置）┐
 → call1 打分（融合副语言）          ├─ Promise.all 并行
 → 记忆召回 + 压缩                   ┘
 → decideMode（crisis.level ≥1 → careful）
 → L3 组装 prompt：careful + BLOCK_SAFETY（A）
                   + [CRISIS_RESOURCES]（B，refer 时）
                   + BLOCK_BOUNDARY（boundary 时）
 → 流式生成 → 逐句 TTS
 → refer 时 sendControl 给前端 overlay（C）
```

## 十、评测（安全金标测试集）

> 安全很重要，单独配金标。分层语料（无风险 / 黄旗 / 红旗，各若干条，含反讽/比喻反例），直接测 `SafetyGuard.check()`：

| 指标 | 含义 | 目标 |
|---|---|---|
| 召回率 | 黄旗/红旗语料被 `level ≥ 1` 检出的比例 | 越高越好（红旗尽量 100%） |
| 误报率 | 无风险语料（含反讽/比喻）被误判 `level ≥ 1` 的比例 | 越低越好 |
| level 判定准度 | 黄旗/红旗是否判到正确的档（1 vs 2） | 越高越好 |

> 跑批脚本 `run-safety-eval.ts` 复用 `turn`/`safetyGuard` 依赖注入，不碰真实语音链路；可选上报 LangFuse（同 `run-eval.ts`）。
