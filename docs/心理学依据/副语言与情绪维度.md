# 副语言与情绪维度（语音情绪识别 / SER）

> 声音（副语言）可靠地给出「唤醒」，但基本给不出「正负」；正负要靠文字语义。

## 结论（被证实了什么）

- 副语言特征（音高 F0、能量、语速、停顿、抖动 jitter、谐噪比 HNR 等，见 eGeMAPS 88 参数）能稳定提取。
- **唤醒（arousal）与声音激活强相关**：音高、能量、语速是唤醒的强编码，是 SER 里预测最稳的维度。
- **效价（valence）从纯音频预测不可靠**：连续情绪识别里，音频效价的 CCC 仅约 0.12–0.38，远差于唤醒；valence 需要文字/语义与上下文。

## 实证强度

**唤醒：强；效价：弱**。这是 SER 领域反复验证的结论。

## 关联的产品决策

- **副语言只判「唤醒」**（响度/音高/语速/停顿），并作为「拆穿逞强」的辅助；**正负交给主模型的文字语义**。
- 说话人标定：响度/音高因人而异，特征要做「相对她自己历史基线的 z-score」，而非绝对值——我们的多轮 EMA 基线天然是标定。
