# 非言语发声检测（哭 / 笑 / 叹气）

> 哭/笑/叹气是离散的非言语发声事件，用声音事件检测模型捕捉，不依赖语言。

## 结论（被证实了什么）

- 哭、笑、叹气属于「声音事件 / 非言语发声」，可由声音事件检测（SED）模型识别，与语言无关（笑/哭/叹气是生理性的、跨语言通用）。
- AudioSet 声音本体（527 类）含 Laugh / Cry / Sob / Sniffle / Sigh，**PANNs CNN14**（~80M 参数，AudioSet 预训练）可一个模型多标签一次全给，CPU 实时。
- 主流 ASR（如 Deepgram）**不提供**哭/笑/叹气检测，且其 sentiment 仅 REST、不支持流式——故需自接模型。

## 实证强度

**中**。模型成熟（零训练直接用），但 sigh（叹气）歧义大、recall 一般；建议只做笑/哭。

## 关联的产品决策

- 定义 **`VocalizationEventDetector`** 缝（输出 `{ type: 'laugh'|'cry'|'sigh', t, confidence }`），第一片只留接口、后期插模型，不动主链路。
- 这是「副语言摘要」的一个事件源，与响度/音高/停顿等连续特征一起，交给主模型融合打分。
