# 心境与情感的区分（MSE）

> 临床把情绪拆成「持续的内在状态」和「瞬时的外在流露」两层，且两层不一致本身是信息。

## 结论（被证实了什么）

- 精神状况检查（Mental Status Examination, MSE）是精神科/心理问诊的标准框架，情绪域的核心区分是：
  - **Mood（心境）**：持续、内在、自述的情绪状态（「你最近感觉怎样」）。
  - **Affect（情感/表情）**：瞬时、外在、被观察到的情绪流露（从表情、语气、表达幅度读出）。
- Affect 由四个属性描述：质量、范围（宽→受限→迟钝→平淡）、强度、**适切性/一致性**。
- **情感不协调（incongruent affect）**：自述与外在表现不一致（如嘴上「我很好」、语气却低落），这本身就是重要的临床信号。

## 实证强度

**强**。MSE 是临床标准框架，mood/affect 区分被普遍采用。

## 关联的产品决策

- **情绪打分拆两层**：每轮主模型读「她刚说的话」= affect（瞬时）；多轮 EMA 轨迹 = mood（持续）。
- 「自述 vs 观察不一致」= 情感不协调 → 触发「小心翼翼」（对应 [自述与观察情绪的不一致](自述与观察情绪的不一致.md)）。
