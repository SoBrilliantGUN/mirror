# 八维认知功能与 MBTI（Jung / Myers-Briggs）

> MBTI 的八维认知功能适合当「写人格的素材」，但作为测量工具信效度有限——只借框架、不做诊断。

## 结论（被证实了什么）

- **Jung（1921）心理类型**：四种功能（思考 T / 情感 F / 感觉 S / 直觉 N）× 两种态度（内倾 i / 外倾 e）= 八种认知功能（Ne/Ni/Se/Si/Te/Ti/Fe/Fi）。
- MBTI 在此之上加了 J/P 维度，形成 16 型。
- **诚实标注其局限**（学界主流批评）：
  - 重测信度低（约 5 周后 ~50% 被测换成另一型）。
  - 强迫二选一，而多数人格特质是连续分布、不是两组。
  - 因子分析未稳定支持其结构；与 Big Five 等维度模型不符。
  - 存在巴纳姆效应（描述宽泛正面，让人「觉得准」）。
  - 16 型与 Jung 原始 8 功能不严格同构。

## 来源（论文 / 文献）

- [火遍全网的 MBTI，为什么心理学家不买账 — 科普中国](https://h5.kepuchina.cn/scientificwebsite/article?id=754057)

## 实证强度

**作为测量工具：弱**（信效度受质疑）；**作为叙事/写作框架：可用**。

## 关联的产品决策

- **只作「写初始人格的素材」**：MBTI 用于写 16 位陪伴者的人设底色，绝不对用户展示、不诊断、不贴标签（避免刻板印象 backlash）。
- **八维认知功能**（Fi/Fe/Ti/Te…）用作理解用户「成长课题」的抓手，而非给她贴一个类型标签。
- 呼应 `docs/产品方案.md` 系统 3、4 的「边聊边读」「不展示 MBTI」原则。
