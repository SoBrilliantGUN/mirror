# 维度严重度打分与阈值分级（DSM-5 / PHQ-9 / GAD-7）

> 现代临床用「维度严重度打分 + 分带 + 阈值」替代「有没有病」的范畴判断。

## 结论（被证实了什么）

- **DSM-5 跨诊断症状量表（Cross-Cutting）**：13 个症状域，每项打 0–4 分（0 无 / 1 轻微 / 2 轻 / 3 中 / 4 重），按频率锚定；**≥2 触发进一步追问，自杀意念/精神病类 ≥1 即触发**。
- **PHQ-9（抑郁）/ GAD-7（焦虑）**：每条 0–3、锚定「过去两周」，加总分 → 分带（0–4 极轻 / 5–9 轻 / 10–14 中 / 15–19 中重 / 20–27 重）；**≥10 = 黄旗，15 = 红旗**；PHQ-9 第 9 条 = 自杀意念，单独盯。

**强**。这些量表是国际通用、被广泛验证的临床工具。

## 关联的产品决策

- **情绪维度分级**：把三维打分映射成**黄旗 / 红旗两档阈值**，而不是简单的二值切换（见 `docs/技术方案.md` 第三层）。
- 参考「频率锚定」：我们的「多轮 EMA 轨迹」天然覆盖「持续性」，可显式补一个「同一负面状态持续了多少轮」的信号。
