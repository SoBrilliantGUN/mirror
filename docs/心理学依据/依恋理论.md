# 依恋理论（Attachment Theory）

> 早期与照护者的依恋关系会塑造一个人成年后在关系里的「内在工作模型」，但依恋是「倾向」而非固定标签。

## 结论（被证实了什么）

- 依恋理论（Bowlby 1950s；Ainsworth「陌生情境」实验）提出婴儿依恋三型，Main 增补第四型，后延伸至成人（Hazan & Shaver 1987；Bartholomew & Horowitz）：
  - **安全型（secure）**：信任他人、亲密与独立皆自在。
  - **焦虑型（anxious / preoccupied）**：渴望亲密又怕被抛弃、常寻求反复确认。
  - **回避型（avoidant / dismissing）**：回避情感亲密、压抑感受、遇亲近就退。
  - **混乱型（disorganized / fearful-avoidant）**：既渴望又恐惧亲近，出现「推拉」。
- 关键边界：依恋是**随关系与时间变化的倾向，不是永久人格类型**；「习得的安全感」可通过支持性关系与自我觉察获得。
