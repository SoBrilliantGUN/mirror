# 心理学依据 · 目录

> 本目录收录**心理学 / 临床评估 / 情感计算中被实证的结论**，作为产品设计决策的出处。
> 目录按「**决策结论**」组织——每条直接给出「我们据此怎么做」，依据细节在对应 MD 文件里。
> 决策的完整上下文见 [`docs/产品方案.md`](../产品方案.md)（产品理念）与 [`docs/技术方案.md`](../技术方案.md)（技术架构）。

## 一、情绪的结构与打分

1. **情绪打分用「效价 × 唤醒 × 支配」三维，不贴离散标签**（愤怒/悲伤等格子处理不了五味杂陈）→ [PAD 三维情绪模型](情绪维度模型-PAD.md)
2. **情绪拆两层**：每轮读「她刚说的话」= 瞬时情感(affect)；多轮 EMA 轨迹 = 持续心境(mood) → [心境与情感的区分](心境与情感的区分.md)
3. **三维分设黄旗/红旗两档阈值**（而非二值切换），并参考「频率/持续性」锚定 → [维度严重度打分与阈值分级](维度严重度打分与阈值分级.md)

## 二、声音（副语言）

4. **副语言权重高于文字**：在「判断情绪/态度 + 通道冲突」场景下 ≈ 7% 文字 / 38% 语气 / 55% 肢体；但我们只做「文字 + 声音」，55% 肢体走计算机视觉、主动不做 → [副语言权重-7-38-55法则](副语言权重-7-38-55法则.md)
5. **副语言只判「唤醒」**（响度/音高/语速/停顿），正负交给文字语义；特征做「相对她自己基线的 z-score」而非绝对值 → [副语言与情绪维度](副语言与情绪维度.md)
6. **文字与声音两路打分，打架 = 情感不协调 = 拆穿逞强**（嘴上没事、声音在抖 → 触发小心翼翼）→ [自述与观察情绪的不一致](自述与观察情绪的不一致.md)
7. **哭/笑/叹气只做「笑 + 哭」**，叹气歧义大、放弃（靠文字兜）；第一片只留缝、后期插模型 → [非言语发声检测](非言语发声检测.md)

## 三、关系、记忆与人格

8. **依恋类型决定亲近节奏**：焦虑型多给确定感、回避型不逼、混乱型做安全基地；依恋是「倾向」不是标签，靠对话揣摩、不测试不贴标签 → [依恋理论](依恋理论.md)
9. **记忆分层 + 遗忘曲线淡化**：核心/重要/普通三级；普通记忆按艾宾浩斯曲线衰减，近期/反复提及即强化，跌破阈值「归档不删除」 → [艾宾浩斯遗忘曲线](艾宾浩斯遗忘曲线.md)
10. **共情三条件 + 治疗联盟**：真诚、无条件积极关注、共情；联盟 = 目标/任务/情感纽带三要素 → 落地为「先接住→映照→引导→落回当下」→ [人本主义倾听与治疗联盟](人本主义倾听与治疗联盟.md)
11. **MBTI 只作「写初始人格的素材」**，不诊断、不展示、不贴标签（其信效度作为测量工具偏弱）；八维认知功能作成长课题抓手 → [八维认知功能与MBTI](八维认知功能与MBTI.md)

## 四、评测方法论

12. **评测层采用 CompanionBench**：10 项关系能力（含 C5 容忍模糊性 / C8 校准式挑战等 4 项新能力）+ 18 反模式红线 + 双轴（rubric 打分 + 披露门），用来把「实质性关系支持」和「表演出来的温暖」分开 → [CompanionBench 论文（PDF）](2608.02046v2.pdf)；能力→本产品四步内核的用例映射见 [`docs/评测用例.md`](../评测用例.md)，可直接运行的评分 prompt 见 [`docs/评测prompts.md`](../评测prompts.md)
