# character/ — 陪伴者角色库

16 位陪伴者（16 型 MBTI，男女各 8 位）的角色文件，全部集中在这里。**人物的所有描述只放在本目录，项目其他位置不存。**

## 目录结构（一个人一个文件夹）

```
character/<姓名>/
├── 角色卡.md     # 核心人设（常驻，始终注入）
├── 记忆.md       # 记忆索引/目录（常驻）—— 一行一条：标题 + 触发钩子 + 链接
├── 关系.md       # 用户与此位陪伴者的关系（常驻；每位独立，不混用）
├── 认知/         # 世界观条目，一条一个文件（命中触发才加载）
├── 经历/         # 人物小传 + 人生片段，一条一个文件（命中触发才加载）
└── 偏好/         # 习惯/口味/怪癖，一条一个文件（命中触发才加载）
```

## 渐进式加载机制（像 Claude 的记忆）

- **`角色卡.md`（常驻）**：身份、性格矛盾、说话方式、红线、对话示例——光靠它，TA 就能在大多数回合立住人设。
- **`记忆.md`（常驻）**：一份"目录"，只存「标题 + 一句话钩子 + 链接」，不装详情。它很小，让运行时知道"有哪些细节、什么时候该想起来"。
- **`认知/` `经历/` `偏好/` 下的详情文件（按需）**：一条一个文件，命中 `记忆.md` 里的触发钩子，才按链接加载对应详情；话题离开即卸载。

> 思路：像 Claude 的记忆系统——`MEMORY.md` 是常驻索引（标题 + 链接 + 一句话），每条记忆的详情是单独一个文件，用到才读。上下文不撑爆，细节也立得住。
